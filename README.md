# Акция в честь дня рождения Светланы Битт

Промо-лендинг клуба «Вечная фаза». Одна страница, без сборки и без бэкенда:
открывается как обычный `index.html`.

## Состав

```
index.html                     вся страница: разметка, стили, скрипты
.nojekyll                      отключает Jekyll на GitHub Pages
sveta_img/
  mobile_version.mp4           hero-видео для экранов < 768px
  pc_version.mp4               hero-видео для экранов >= 768px
  hero_poster_mobile.jpg       первый кадр мобильного ролика
  hero_poster_pc.jpg           первый кадр ПК-ролика
  logo.svg                     знак клуба, красится через currentColor
  sveta_quote.jpg              портрет для блока с цитатой
  decor/                       спрайты фольги для фона
  _original_hevc/              исходники в HEVC (не коммитятся, см. .gitignore)
serve.py                       локальный сервер с поддержкой Range
404.html                       страница «не найдено»
```

Внешние зависимости грузятся с CDN: Tailwind, GSAP + ScrollTrigger,
canvas-confetti, Google Fonts. Если любая из них не приедет, страница
всё равно откроется — контент виден по умолчанию, прячет его только
класс `js-ready`, который снимается аварийным таймером.

## Локальный просмотр

Двойной клик по `index.html` работает, но **скролл по видео при этом
может не заработать**: для перемотки браузеру нужны HTTP Range-запросы.

Правильный способ — поднять сервер с их поддержкой:

```bash
python serve.py 5174
```

Затем открыть <http://localhost:5174>.

Обычный `python -m http.server` **не подходит**: он игнорирует заголовок
Range, из-за чего `video.seekable` пустой и скраб не работает вовсе.

## Что нужно заменить перед запуском

В `index.html` два места помечены комментарием `TODO` — кнопки заявки.
Сейчас обе ведут на якорь `#cta`:

- «Выбрать тариф для продления» — в hero и в финальном блоке
- «Получить индивидуальное предложение» — в блоке тарифов

Подставьте ссылку на Telegram или форму оплаты.

## Дедлайн акции

Дата зашита одной строкой в `index.html`:

```js
const DEADLINE = new Date('2026-09-15T23:59:00+03:00').getTime();
```

Когда срок выйдет, таймер сам скроется, появится «Набор закрыт»,
а обе кнопки станут неактивными.

## Перекодирование видео

Скролл по видео требует частых ключевых кадров и H.264 — HEVC не играет
в Firefox и в Chrome на многих машинах. Текущие файлы получены так:

```bash
ffmpeg -i sveta_img/_original_hevc/pc_version.mp4 \
  -c:v libx264 -profile:v high -level 4.2 -pix_fmt yuv420p \
  -g 12 -keyint_min 12 -sc_threshold 0 \
  -crf 18 -preset slower \
  -movflags +faststart -an \
  sveta_img/pc_version.mp4
```

`-crf 18` — качество; меньше число значит лучше картинка и больше файл.
`-g 12` даёт ключевой кадр каждые полсекунды, без этого перемотка дёргается.
`+faststart` кладёт индекс в начало файла, чтобы видео стартовало сразу.

## Вес страницы

| | загружается |
|---|---|
| Мобильный | ~9.6 МБ |
| Десктоп | ~8.8 МБ |

Основной вес — hero-видео (8–9 МБ). Грузится ровно один ролик,
нужный под ширину экрана.
